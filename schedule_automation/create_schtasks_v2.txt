:: 작업 스케줄러에 Python 스크립트를 직접 등록하는 명령어
:: cmd (관리자 권한 불필요, 일반 cmd 가능)에서 아래 6줄을 순서대로 실행
::
:: ⚠ 경로 주의사항
:: - /tr 경로에 공백이 있으면 schtasks가 잘라서 오류 (0x80070005)
:: - pythonw.exe 경로와 py 파일 경로를 각각 \"...\" 로 감싸야 공백 처리 가능
:: - python.exe 대신 pythonw.exe 사용 → 실행 시 cmd 창이 뜨지 않음
:: - 작업명(/tn)에는 공백 넣지 말 것
:: - /ed 2026/10/15 는 예시(캠페인 종료일) — 실제 종료일로 교체할 것
:: - 아래 중 이 폴더에 있는 것은 check_mail_attachment.py 와 update_schedule*.py 뿐이다.
::   check_mail_attachment_byname/_status/_url.py, mail_search_to_msg_onlymsg.py,
::   summarize_msgs.py 는 별도 repo(mail_search) 의 도구 — 같은 스케줄 묶음으로 돌리는
::   예시라 함께 적어둔다. /tr 경로는 그 repo 를 받아둔 위치로 바꿀 것.
::   https://github.com/jjonghyunn/mail_search
::
:: ─── 실행 시각 배치 (분 단위 중복 없게) ───
:: 09:57 /mo 60  cmp_mail_search_to_msg
:: 10:01 /mo 20  cmp_mail_check              (→ :21 :41 반복)
:: 10:02 /mo 60  cmp_summarize_msgs
:: 10:03 /mo 60  cmp_mail_check_status
:: 10:04 /mo 20  cmp_schedule_update         (→ :24 :44 반복)
:: 10:06 /mo 60  cmp_mail_check_url

schtasks /create /tn cmp_mail_check /tr "\"C:\Python3xx\pythonw.exe\" \"C:\Users\user_name\OneDrive - company_name\user_id\your_folder\your_workspace\260324_schedule\check_mail_attachment_byname.py\"" /sc minute /mo 20 /st 10:01 /ed 2026/10/15 /it /f

:: ─── 배터리 모드 허용 (위 schtasks 등록 후 실행) ───
:: schtasks는 배터리 조건을 직접 설정할 수 없으므로 별도 적용 필요

:: [cmd/bat에서 실행] powershell.exe 래퍼 사용

powershell -Command "$names = 'cmp_mail_check','cmp_schedule_update','cmp_mail_check_status','cmp_mail_search_to_msg','cmp_summarize_msgs','cmp_mail_check_url'; foreach ($n in $names) { $t = Get-ScheduledTask -TaskName $n; $t.Settings.DisallowStartIfOnBatteries = $false; $t.Settings.StopIfGoingOnBatteries = $false; Set-ScheduledTask -InputObject $t }"

:: [PowerShell 창에서 직접 실행] 래퍼 없이 한 줄 (더 빠름, 권장)
:: ⚠ PS 창에서 위 `powershell -Command "..."` 형태를 쓰면 바깥 PS가 $names·$n·$t를
::   자기 변수로 먼저 치환(빈 값)해버려 "foreach 뒤에 변수 이름이 없습니다" 오류 발생

$names = 'cmp_mail_check','cmp_schedule_update','cmp_mail_check_status','cmp_mail_search_to_msg','cmp_summarize_msgs','cmp_mail_check_url'; foreach ($n in $names) { $t = Get-ScheduledTask -TaskName $n; $t.Settings.DisallowStartIfOnBatteries = $false; $t.Settings.StopIfGoingOnBatteries = $false; Set-ScheduledTask -InputObject $t }
